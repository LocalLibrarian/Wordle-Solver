# Wordle Solver
## Description
This is a personal project I made that attempts to solve a given Wordle puzzle (https://www.nytimes.com/games/wordle/index.html).
## Requirements
A JVM, and Maven to build.
## How to Use
If you want to re-scrape all the data in words.txt, you can rerun the webScraper program and it will do so. The dataset should never change though since it is pretty doubtful any new 5-letter words added to the English language would be used in Wordle. <br> <br>
If you want to make a random sample of any size from the dataset, you can run sampler and input the sample size. <br> <br>
If you want to check the accuracy of each algorithm that I've implemented, you can run statsGatherer and follow the input as requested.
